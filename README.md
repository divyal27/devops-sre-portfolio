# DevOps, DevSecOps & SRE Platform Portfolio

A production-grade, human-crafted portfolio for **Divyal Padalkar** built with **React**, **Vite**, **Tailwind CSS**, and **Lucide Icons**, following the [Unslop](https://github.com/heydamir/unslop) design principles.

Live deployment target: **Vercel Edge** with automated GitOps CI/CD.

---

## 🚀 Key Features

* **3-Role Interactive Cockpit:** Dynamically switches between **DevOps**, **DevSecOps**, and **Site Reliability Engineering (SRE)** with real architecture flowcharts and repository highlights.
* **Production Telemetry Stat Strip:** Highlighting verifiable impact metrics (-35% MTTR reduction, ~50% setup time reduction, -30% deployment failures).
* **Interactive DevOps CLI Console (`Ctrl + ~`):** Realistic simulated terminal supporting commands like `kubectl get pods`, `gitops status`, `slo report`, `cat resume.json`, and `security audit`.
* **Verified Credentials:** Showcases certifications from Anthropic (Claude API & Claude Code) and AWS (Advanced Testing Practices Using AWS DevOps Tools).
* **Zero AI-Slop Design:** Deep graphite palette, quiet 1px hairline borders, monospaced telemetry typography, and deliberate 4px spacing rhythm.

---

## 🛠️ Tech Stack

* **Frontend:** React 19, Vite, Tailwind CSS, Lucide Icons
* **Hosting:** Vercel (Edge Network & CI/CD)
* **Domain Focus:** AWS EKS, Kubernetes, ArgoCD, Terraform, Prometheus, Grafana, Trivy, SonarQube, Ansible

```bash

# 2. Run local development server
npm run dev

# 3. Build production bundle
npm run build
```
